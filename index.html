In fintech, security is a fiduciary duty. People connect their bank accounts, investments, and spending history so they can make better decisions with their money. That only works if they can trust the platform with it. I build the systems that earn and keep that trust.

I'm a security engineer with more than ten years of experience, and I do most of my work in code. I build cloud guardrails, detection pipelines, and internal tooling the same way product teams build features: version-controlled, tested, reviewed, and shipped often. My background runs from enterprise networking and PKI up through cloud, containers, identity, and now AI, which helps me see how the whole stack fits together.

what I do now

I work at a personal finance platform that brings together people's accounts, budgets, and investments in one place. My work covers six areas:

agentic SOC & detection
  • An agentic SOC where AI agents triage alerts, gather context, and draft findings, so people spend their time on decisions.
  • Security telemetry in Datadog and Sumo Logic, with detections written, tested, and deployed as code.
  • 24/7 coverage with Expel as our MDR partner, and incident response from first alert to lasting fix.
AI, agents & MCP
  • Governing how AI agents reach company tools and data over MCP, using MintMCP for access control and audit.
  • Building MCP servers, Slack bots, and agent workflows with Claude Code and Devin; prototyping internal tools on Replit.
  • Threat modeling AI features for prompt injection, data leakage, and over-permissioned agents.
cloud & edge security
  • Cloud posture and runtime risk in Wiz, with GuardDuty threat detection across AWS.
  • Edge protection with Cloudflare: WAF, bot management, and zero trust access.
  • Security guardrails defined in Terraform and enforced in CI, so the secure setup is also the default one.
identity & endpoint
  • Okta and Google Workspace as the identity foundation, with least-privilege access for people and services.
  • CrowdStrike on every endpoint, and Macs managed with Kandji and Jamf.
application security & financial data
  • Semgrep and GitHub Advanced Security on every pull request, covering code, secrets, and dependencies.
  • Securing the account-aggregation integrations (Plaid, MX, Finicity) that connect people's financial institutions.
  • Protecting customer financial data through encryption, data minimization, and tight access controls.
vendor risk & automation
  • Third-party risk reviews in VISO TRUST, built into purchasing through Zip, so security review happens before a contract is signed.
  • Slack bots and automations that connect security work to Linear and Notion, so requests and evidence don't get lost.

how I work

🧱
Security is software. Controls, detections, and policies live in Git, run through CI, and get code review like everything else.
🛣️
Paved roads, not gates. The best control is a secure default that engineers would pick anyway, because it's also the easiest option.
🤝
Act in the customer's interest. Collect less, protect what we keep, and be ready to explain every access decision.
⚡
AI as leverage. I use AI tools every day to ship faster, and I hold AI features to the same security standard as any other code.
